# Logo Edit Instructions

## Creating the Red Heart Variant

The original VibeFlow logo is stored at `/public/brand/logo.png`.
To create the red-heart variant (`/public/brand/logo-redheart.png`):

### Using an Online Editor (e.g., Photopea.com)

1. Go to https://www.photopea.com
2. Open `/public/brand/logo.png`
3. Select the heart shape using the Magic Wand or Quick Selection tool
4. Go to **Image → Adjustments → Hue/Saturation**
5. Shift the Hue slider to target red tones (~0-10 degrees)
6. Increase Saturation to ~80-90%
7. Adjust Lightness for a romantic red gradient effect
8. Export as PNG: **File → Export As → PNG**
9. Save as `/public/brand/logo-redheart.png`

### Color Reference
- Target heart color: Romantic red gradient
- Primary red: `#E53E3E` to `#C53030`
- Keep the original shape, shading, and wave elements unchanged
- Only recolor the heart element

### Files
- Original: `/public/brand/logo.png`
- Red variant: `/public/brand/logo-redheart.png` (create manually)
