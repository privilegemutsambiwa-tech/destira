You are a senior UI/UX designer and frontend engineer. Your task is to redesign VibeFlow's entire user interface to be maximally professional and polished. Every detail matters: spacing, color, typography, visual hierarchy, and interaction feedback.

---

DESIGN SYSTEM (Apply Everywhere)

Color Palette:
- Primary: #7C3AED (Purple) — Use for CTAs, active states
- Secondary: #EC4899 (Pink) — Use for accents, highlights
- Accent: #F59E0B (Amber) — Use for stories, badges, notifications
- Neutral Dark: #1F2937 (for text)
- Neutral Light: #F3F4F6 (for backgrounds)
- Success: #10B981 (green, for verified badges)
- Danger: #EF4444 (red, for reject/dislike)

Typography:
- Headlines (H1): 28px, Bold, #1F2937
- Subheads (H2): 20px, Semibold, #1F2937
- Body: 16px, Regular, #374151
- Small text: 14px, Regular, #6B7280
- All fonts: Use system fonts (SF Pro Display on iOS, Segoe on Windows)

Spacing:
- Use 8px base unit (8, 16, 24, 32, 40, 48px)
- Card padding: 16px or 24px
- Section gap: 24px to 32px

Shadows & Depth:
- Card shadows: 0 2px 8px rgba(0,0,0,0.08)
- Hover shadows: 0 8px 16px rgba(0,0,0,0.12)
- Use subtle elevation, not dark shadows

Border Radius:
- Cards: 12px
- Buttons: 8px
- Profile images: 16px (slightly rounded)
- Story rings: 2px (thin border)

DISCOVER PAGE (Main Swiping Interface) ⭐ MOST IMPORTANT

This is where users spend 80% of their time. Make it PERFECT.

Layout Structure:
- Top bar: Simple back arrow (optional), centered name "Discover", no other elements
- Main content: Full-screen card (95% width, centered, 16px margin)
- Bottom: Two action buttons side by side

Card Design (Shows one profile at a time):
1. Profile Image Container (Top):
   - Aspect ratio: 1:1.2 (portrait)
   - Border radius: 16px
   - Image fills entire container with subtle gradient overlay on bottom
   - Overlay gradient: transparent → rgba(31, 41, 55, 0.6) (dark fade at bottom)
   - STORY RING (if user has stories):
     * Thin circle border (2px) around top-left corner
     * Border color: #F59E0B (amber)
     * Diameter: 48px
     * Centered position: top-left with 12px margin
     * Contains: Small centered text "Story" or just show a play icon (▶️)
     * Interactive: Tappable to view their story carousel

2. Profile Info (Overlay on bottom of image):
   - Position: Absolute, bottom of card
   - Background: Dark overlay (rgba(31, 41, 55, 0.8))
   - Text color: White
   - Padding: 24px
   - Name: 28px bold, white
   - Age & Location: 16px regular, light gray
   - Example: "Sarah, 28 • San Francisco, CA"
   - Add subtle location icon (📍) before location

3. About Section (Below image, inside card):
   - Padding: 24px
   - Background: White
   - "About": 16px bold, dark gray
   - Bio text: 16px regular, #374151, line-height 1.5
   - Margin bottom: 16px

4. Personality Traits (Below bio):
   - Show 3-4 traits as badges/pills
   - Badge style: Light purple background (#EDE9FE), purple text (#7C3AED)
   - Badge spacing: 8px between each
   - Example: "Openness: 92%" | "Extroversion: 65%" | "Neuroticism: 35%"
   - Font: 12px, semibold

5. Actions Section (Below personality):
   - Padding: 24px
   - Two buttons side by side (equal width, 16px gap):
     * LEFT button (REJECT): 
       - Icon: ❌ (or X symbol)
       - Background: #FEE2E2 (light red)
       - Text color: #EF4444 (red)
       - Label: "Pass" (optional, can be icon-only)
       - On tap: Slight bounce animation, card slides left
     * RIGHT button (LIKE):
       - Icon: ❤️ (or heart symbol)
       - Background: #FCE7F3 (light pink)
       - Text color: #EC4899 (pink)
       - Label: "Like" (optional, can be icon-only)
       - On tap: Slight bounce animation, card slides right

6. Card Transitions:
   - When user taps Pass → Card slides out to left (0.3s animation)
   - When user taps Like → Card slides out to right (0.3s animation)
   - Show next card with a fade-in + subtle scale animation (0.2s)
   - Add haptic feedback (vibration) on each action
